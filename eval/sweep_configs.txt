# name|args   -- the sweep that tuned the paired defaults, on chr1:1-25000000
# (317 truth records in scope). F1 on the records row.
#
# Two things this measured, both of which changed the defaults:
#   * --som-pval never rejected a single false positive anywhere between 1e-3
#     and 1.0: FP stayed pinned at 6 while TP rose 176 -> 190. The four-slot
#     structural constraints carry precision on their own, so the Fisher test
#     was pure recall loss.
#   * -a (candidate alt-ratio) only pays off once the p-value is relaxed:
#     -a 0.10 alone gains 2 TP, but with the p-value off it gains 33. Lowering
#     one without the other wastes it, because the candidates it admits are
#     low-VAF and the Fisher test then rejects them for lack of power.
# -a 0.02 is worse than 0.05 on both counts, so 0.05 is a real interior optimum.
